# ClassMate Vision — Young Innovators Programme

This repository contains a production-ready static website showcasing the "ClassMate Vision" project for the Young Innovators Programme.

Overview
- A futuristic, professional presentation site describing the ClassMate Vision smart classroom concept.
- Focus: explain the project, its benefits, privacy considerations, and roadmap.
- Not a sales page — designed for judges, evaluators, and stakeholders.

Files
- `index.html` — Main page (entrypoint for GitHub Pages).
- `styles.css` — Main stylesheet (glassmorphism, layouts, responsive).
- `script.js` — Lightweight JavaScript for particles, in-view animations, and interactions.
- `README.md` — This document.

How to deploy on GitHub Pages
1. Create a new repository (or use an existing one).
2. Add the files above to the repository root.
3. Commit and push to GitHub.
4. In repository settings > Pages, select the branch (typically `main`) and root folder to enable GitHub Pages.
5. The site will be available at `https://<username>.github.io/<repo>/` (or your custom domain if configured).

Design notes & accessibility
- Built with vanilla HTML/CSS/JS for reliability and low maintenance.
- Uses Google Fonts (Inter, Rajdhani) — free for web use.
- Includes ARIA-friendly roles and respects `prefers-reduced-motion`.
- All interactive behavior is unobtrusive and progressive-enhanced.
